# 🤝 TodoFriends
> 팀 프로젝트 | 2026.03 ~ 2026.04

Kotlin과 Jetpack Compose 기반의 AI 소셜 일정 관리 Android 애플리케이션입니다.<br/>
개인의 할 일 관리뿐 아니라 친구 및 팀 단위의 일정 조율을 돕고, AI를 활용해 효율적인 하루 일정을 구성할 수 있도록 기획했습니다.

## ✨ 주요 기능
- 📝 할 일 관리 - 할일 등록 및 일정 관리
- 🤖 AI 개인 일정 추천 - 할 일과 소요 시간을 바탕으로 하루 일정 추천
- 👥 AI 팀 일정 추천 - 팀 단위의 공동 일정 추천
- 🔄 추천 결과 적용 및 재추천 - AI 추천 결과를 할 일 목록에 적용하고 다시 추천 요청

## 🛠 기술 스택
| 구분 | 기술 |
|------|------|
| Android | Kotlin, Jetpack Compose |
| API 통신 | Retrofit2 |
| AI | OpenAI API |
| 디자인 | Figma |
| 협업 및 버전 관리 | Git, GitHub |

## 💡 기획 배경
기존의 투두리스트 앱이 개인의 할 일 관리에 집중한다는 점에서 출발해, 친구 및 팀과의 일정 조율까지 지원하는 서비스를 기획했습니다. AI를 활용해 단순한 할 일 기록을 넘어 효율적인 하루 일정 구성을 돕고자 했습니다.

## 👩‍💻 담당 역할

- Kotlin과 Jetpack Compose 기반 Android 프론트엔드 개발
- OpenAI API 연동 및 AI 일정 추천 기능 구현
- AI 추천 응답 처리 및 추천 결과 적용·재추천 기능 개발
